# Switcher Pet 自用版产品设计

日期：2026年11月6日。状态：开发预览；隔离基础、部分路由修复、模型配置、额度与探针页及桌宠入口已有实现。设计全文是目标范围，不代表所有条目均已交付；实测范围以README.selfuse.md为准。

目标是把多账号 Switcher 改成一个可信的模型路由器，再以拟人桌宠作为日常入口。兼容性修复是第一阶段，不以换皮替代工具调用、子智能体路由、Google 适配和长对话压缩的改善。

## 1 产品边界

- 保留 Codex 原生模型选择体验；桌宠菜单与客户端目录使用同一份逻辑模型注册表。
- 区分模型身份、接入平台、协议、账号、能力和皮肤。Google 平台上的 Claude 应显示 Claude 形象，而不是 Gemini。
- 不宣称所有第三方模型都拥有 OpenAI 托管工具、相同上下文格式或相同推理能力。
- 不修改当前安装目录、当前账号库、Codex 配置、登录文件或当前代理；只在独立 fork 开发。
- 桌宠不是新的聊天客户端，也不需要再运行一整套 DSH。只复用经许可的素材和交互思想，不执行下载插件的脚本。

## 2 桌宠交互

### 常用操作

| 操作 | 行为 |
|---|---|
| 单击 | 立即显示缓存用量气泡，同时播放一次可关闭的小黄鸭音效；异步刷新，绝不等待网络才显示 |
| 再次单击 | 收起气泡；300ms 内合并重复音效 |
| 拖动 | 超过拖动阈值后移动，不再触发点击音效；支持贴边、多屏和 DPI 变化 |
| 右键 | 打开模型路由菜单，不改变当前模型 |
| 气泡内点击 | 切换总池／当前账号，或打开用量详情 |
| 托盘／快捷键 | 即使桌宠隐藏或鼠标穿透，也能恢复和打开设置 |

不使用双击作为关键操作，以免单击查看用量被延迟。支持静音、音量、免打扰时段、全屏自动隐藏、录屏隐私模式、减少动画、恢复默认位置。键盘可访问所有核心功能。

### 新设置中心

不沿用旧账号卡片主页面作为新版入口。日常仅桌宠、气泡和右键菜单；复杂配置打开新设置中心，分为“账号与额度”“模型与来源”“自动切换”“桌宠与声音”“诊断与迁移”。默认不弹管理主窗口。旧页面暂留在开发基线中用于构建回归，不作为最终界面交付。

### 活跃对话与自动换装

默认跟随“最近一次用户主动交互的主对话”，不是最近收到网络包的请求。获得可靠焦点事件时优先跟随前台对话；拿不到焦点时，以最近用户发言／主动选择的主对话为准并标示。

请求实际开始后，按有效模型身份换装；菜单选中但尚未调用时显示“待生效”，不假装已使用。后台探针、额度刷新和子智能体不会抢走主形象。子智能体以角标或小气泡展示；可手动锁定某个对话或某个形象。

多对话并行时显示主对话标签和“另有 N 个任务”，避免一秒换几次角色。模型身份不明时显示通用皮肤，不根据中转站自报名字假装验证了底层模型。同模型来源切换只更新来源提示，不改变角色；只有用户主动选择另一模型才按新模型换装。

状态优先级：需要用户操作 > 错误 > 工具执行 > 思考 > 完成 > 空闲。颜色不能作为唯一状态提示。隐藏或休眠后停止动画，恢复时纠正屏幕位置。

## 3 右键菜单与统一选择器

示意如下，具体模型列表来自当前客户端目录和已启用第三方模型，不硬编码版本：

```text
当前：GPT 模型 A · 订阅账号 1       [实际生效]
作用范围：此对话                 [可切换]

GPT 模型 A  →  ● 自动订阅池
               ○ 订阅账号 1       剩余周额度／健康
               ○ 订阅账号 2       冷却至 14:30
               ○ API 站点甲       上游：模型实际名称
               ○ API 站点乙       上游：模型实际名称
               配置来源…
GPT 模型 B  →  …
──────── 第三方模型 ────────
Claude 模型 →  ● Google / 账号 G
               ○ Anthropic API / 账号 C
               ○ 中转站 / 账号 R
Gemini 模型 →  …
DeepSeek 模型 → …
其他启用模型 → …

子智能体策略 → 继承主对话／独立池／按角色配置
用量显示     → 总池／当前账号／选择账号
桌宠         → 自动换装／固定形象／静音／隐藏
设置…         诊断…         暂停新请求路由…
退出桌宠      退出全部服务…
```

原生模型维持客户端提供的排序；第三方按用户固定顺序、模型家族和版本排列，支持搜索与收藏。来源只用第二级菜单，不增加账号型号组合造成的上百个重复模型。

“退出桌宠”只关外观，不停止正在承载聊天的代理。“退出全部服务”在有进行中任务时提示等待或显式中断，避免一关桌宠整个 Codex 断线。

### 必须显式呈现的规则

1. **选择模型与选择来源不同。** 菜单更改来源是代理控制；如果没有受支持的客户端接口，它不能直接替用户更改原生输入框里选中的模型。此时提示“来源已更新，请在 Codex 选择该模型”，不得谎报双向同步成功。
2. 范围可选“此对话”“此对话及后续子任务”“以后使用此模型的对话”“全局默认”。默认此对话；全局变更需要明确提示影响面。
3. 变更下个安全回合生效。已经开始的流、未配对工具调用和压缩操作固定在当前路由，不在中途改账号。
4. 每个模型配置提供“允许自动切换”复选框。未勾选时固定所选来源，失败明确提示；勾选后只在该模型的已允许账号／来源间切换。绝不自动切换其他模型，不提供跨模型降级开关。同模型付费 API 只有被用户勾选参与并满足费用上限时才可进入候选池。
5. 禁用模型区分“从菜单隐藏”和“禁止新请求”。已有对话给出明确错误和替代建议，不静默改模型；正在执行的回合允许完成。
6. 来源展示协议和实际上游 ID；同名不等于同能力。模型、工具、图片、压缩均有“已验证／部分／不支持／未知”标识。

### 同模型自动切换配置

模型设置中包含“允许自动切换”，每个来源行包含“参与自动切换”和优先级。新模型默认不自动启用；勾选后按当前来源优先、失败冷却后依优先级选择可用来源，避免无故来回切号。

切换只能改变账号或接入来源，保持逻辑模型及明确配置的推理档位和服务要求；不同上游名称必须显式映射到同一逻辑模型，不能用通用 fallback 将其他型号混入。版本不同、能力不足或上下文无法安全续接的来源不能自动接替。

没有可用的同模型来源时，显示“该模型暂无可用来源”，提供等待恢复、重新登录或手动选择的入口；不自动降级、不重复执行已完成工具。用户关闭自动切换后，当前已开始的尝试可结束，但不能再发起新的自动换源尝试。

## 4 路由与子智能体

统一记录逻辑模型 ID、厂商模型 ID、provider、protocol、account、请求角色、父子对话 ID、路由版本和生效回合。展示名称可变，内部稳定 ID 不变。普通请求、WebSocket、压缩、重连必须使用同一个路由决定。

路由优先级：显式任务绑定 > 已验证身份的子智能体策略 > 此对话绑定 > 此模型默认来源 > 全局策略过滤出的同模型池。自动切换开关、同模型约束、安全策略、模型禁用、费用上限和能力要求在所有层级生效；全局策略不能绕过模型级关闭设置。

子智能体可设为：继承父来源、使用独立账号池、按角色绑定（例如审查走 Claude、轻任务走 Gemini）。配置同时说明是共享父历史还是摘要交接，禁止只换模型名而继续传无法兼容的加密历史。

**可实现范围有条件：** 如果子请求经过本地代理，并且客户端提供稳定可识别的子任务身份或显式角色路由，Switcher 可以分流。如果任务在服务端产生且不经过本机，或者客户端在发请求前拒绝第三方模型，代理不能单独解决；需要受支持的客户端扩展或独立执行器。独立执行器应标为另一种执行方式，保留审批、取消、结果回传和数据权限，不能冒充原生子智能体。

当前官方配置有默认子智能体模型和角色配置文件入口，但这不证明任意第三方账号路由在当前桌面端都已获支持。[官方配置说明](https://learn.chatgpt.com/docs/config-file/config-reference)

## 5 四类兼容问题的改善方案

### 工具调用

建立统一的能力表和协议中间表示，不再让所有工具结果经过纯文本归一化。依次补齐函数声明、命名空间、custom/freeform 工具、多轮 call_id 配对、并行乱序、图片与文件工具结果、取消和错误终止。

复杂 Schema 必须做可验证转换；无法等价转换时在能力检查中报出缺口，不通过删除约束伪装兼容。普通客户端函数／MCP 工具和 OpenAI 托管搜索等云服务分别处理。后者只能透传给支持的后端，或由用户明确选择替代服务，不能只改函数名。

### Google 平台非 Gemini

拆开“平台”和“模型家族”。Google Antigravity 的 Claude、GPT OSS 与 Gemini 使用各自验证过的参数和能力档案。与 Gemini API、Vertex 的认证和接口也分开，不共用错误假设。

先记录经过脱敏的请求类别、有效模型、HTTP 状态、上游错误码、工具阶段、签名是否存在；禁止默认收集完整对话、密钥和全部请求头。按账号权限、模型下线、参数冲突、思考签名、Schema、限流分类。

“所有非 Gemini 都报错”目前是用户反馈，不是已定位到同一根因的结论。每个模型须通过纯文本、普通工具两轮、custom 工具两轮、图片结果、压缩后续聊矩阵，才能标为支持。

### 子智能体

消除 HTTP／WebSocket 路由优先级差异；不以全局 current 作为临时覆盖手段。先用离线多会话并发夹具证明不串号，再在隔离测试客户端验证真正的父子请求。

### 压缩

区分三件事：网络压缩、工具输出截断、对话上下文压缩。这里解决第三项。

- 原生压缩：只向经过探针验证的 `/responses/compact` 或原生服务端压缩路径发送，保持路由归属和返回历史完整。
- 适配压缩：非原生后端使用“结构化摘要 + 近期消息 + 未完成工具状态”的受支持上下文桥；先验证客户端能接受该续聊方式。验证前显示不支持，不制造假的 OpenAI compaction 对象。
- 跨厂商切换：不能把 OpenAI 不透明压缩块当作可通用解密的数据。需要此前保存的允许保留的可见历史或可携带摘要；没有时提供新对话交接，而不是默默丢历史。
- 失败时保留上个上下文检查点；压缩请求有单独预算、超时和重试上限，不把永久不支持循环伪装成临时 429。

官方说明指出 compaction 项是不透明状态，专用压缩端点返回的整个上下文窗口应完整用于后续请求。[压缩协议说明](https://developers.openai.com/api/docs/guides/compaction)

## 6 模型与余额探针

“v1 API”仅表示常见 URL 约定，不代表一定支持 Responses、工具、图片或余额查询。

设置中的模型表包含：显示名、逻辑 ID、上游 ID、账号来源、协议、目录可见、允许调用、工具、视觉、上下文、压缩方式、价格来源、最近验证时间。支持批量启用、批量禁用、手动添加和恢复；用户禁用状态不被刷新覆盖。

探针分三层：

1. 模型发现：使用该平台模型目录，启动时读取缓存，后台默认每6小时刷新；新发现的模型默认不加入自动池。
2. 额度与余额：仅用该供应商已知的只读接口。活跃账号默认5分钟，非活跃30分钟；遵循 Retry-After、带随机抖动、最大并发2。没有余额接口时显示“未知／仅本地估算”，不显示0元。
3. 能力探测：最小文本、合成函数、图片和压缩测试分项进行。可能计费的测试默认关闭，用户开启后配置每日预算和单次输出上限。不发送真实项目内容，不运行真实 shell 工具，不通过探针刷新原版共享的 OAuth refresh token。

状态：待测、可用、部分可用、短时限流、配额耗尽、需登录、模型不存在、不支持、服务故障、未知。403不等于余额为零，429不一定是周额度耗尽。自动探针作为新应用的后台功能，不创建本次聊天的计划任务。

## 7 用量气泡与计量口径

### 显示示例

以下全部是设计样例，不是本机真实额度：

```text
五小时剩余 ≈ 130% Plus等效     仅受限账号子池
周池剩余 ≈ 530% Plus等效       总容量 1200%
可调用 API 来源 3 个 · 模型 12 个
已知余额 USD 18.20 + CNY 36.00 · 另1个未知
更新于 14:32   [总池 | 当前账号] [详情]
```

上例为存在五小时受限账号的号池；确认池内所有账号均无五小时限制时隐藏第一行，只显示周额度及 API／余额信息。单账号显示自身适用窗口的剩余百分比、套餐／倍率、重置时间、当前模型与来源、已知余额及数据新鲜度。“总池百分比”默认是剩余而不是已用；可切换，但不能无标签混用。

### Plus 等效计算

短窗口和周窗口分别计算，不相加、不直接取两个百分比的最小值。以单个 Plus 对应窗口完整额度为100%。

对某一窗口，账户 i 的权重为 w_i，剩余比例为 r_i（0至1）：

`剩余 Plus 等效百分比 = 100 × Σ(w_i × r_i)`

`总容量 Plus 等效百分比 = 100 × Σ(w_i)`

`池内剩余率 = 100 × Σ(w_i × r_i) / Σ(w_i)`

三个50%剩余的1x账号 = 150% Plus等效，不是50%；一个10x、剩余50%的账号 = 500%等效。单号可显示“剩余50% ≈ Plus周额度500%”。

按用户要求直接采用默认估算倍率，不等待实测或校准。提供1x、10x、20x、50x、100x快捷档和自定义数值；Plus与Business标准席位默认1x，未细分档位的Pro暂按10x估算，用户可直接修改。其他订阅账号可先按1x估算并修改；纯API余额不折算成Plus订阅额度。每个账号可分别覆盖五小时与周倍率，所有等效容量和剩余量统一加“≈”。这些是产品默认估算值，不是官方额度承诺，也不影响上游真实限流的执行。

### 按实际限制自动显示窗口

保留五小时窗口。是否显示由当前号池中账号的实际限制决定，不按 Plus、Pro 或 Business 的名称直接推断。

| 当前号池检测结果 | 主气泡显示 |
|---|---|
| 至少一个账号有五小时限制 | 五小时额度 + 周额度 |
| 所有账号均已确认没有五小时限制 | 只显示周额度，不显示虚构的五小时100%或无限额度 |
| 没有已知受限账号，但存在未检测、检测失败或数据过期的账号 | 暂保留五小时行，标为“限制待确认”，不将缺少数据当成无限制 |
| 号池为空 | 显示“暂无入池账号”，不显示虚构额度 |

号池范围为用户当前选择并启用纳入统计的账号；临时限流、耗尽或需重新登录的账号仍保留其限制类型，不能因为暂不可调度就让五小时行消失。账号增删、入池开关和有效探针结果变化时重新计算显示状态。单账号模式使用同一规则。

五小时等效额度只聚合具有该限制且数据可用的账号，明确标注“仅受限账号子池”；无五小时限制的账号不加入这一分母或被折成无限额度。周额度独立汇总有周配额的账号；部分数据缺失时显示覆盖率，完全没有周配额数据时显示“不适用／未知”，API余额仍独立显示。

短窗口耗尽但周额度仍剩的账号仍计入周库存，同时列为“暂不可调度”。**周池库存不是此刻可以一次性调用的量。** 隐藏五小时行仅改变展示，路由器仍执行上游实际返回的窗口、模型、并发和账号健康限制。

当前官方说明 Plus 等有五小时窗口、Pro 当前没有五小时限制；实际限制和重置仍以账号用量数据为准，不能把当前规则写死成永久逻辑。[官方用量说明](https://learn.chatgpt.com/docs/pricing)

### 余额与用量不能混算

- API 余额按币种分别求和；需要统一币种时用注明时间的汇率，标为估算。
- 现金余额、赠金额度、订阅次数、后付费预算和组织共享额度分开。不能把预算上限当成现金余额。
- 同一计费账户下多个 Key 先去重，再计余额；同一订阅不能因多个令牌重复入池。
- 余额未查询到、已过期、被禁用、登出、部分账号失败，都有单独标记和覆盖率，例如“8/11账号已更新”。
- 可调用 API 来源数是已启用且满足当前模型能力要求的来源数；同时显示去重模型数，防止“模型12个”误解为“12个账号”。
- 本地 token 账本只覆盖经过新代理的流量，不能代替平台全局账单。请求、重试、探针和取消的实际消耗单独记账，按请求 ID／尝试 ID 去重。

## 8 素材插件设计

每套素材为无代码数据包：manifest、图片／图集、可选声音和许可文件。manifest 包含作者、来源、提交版本、SHA256、许可、模型家族、帧布局、锚点、点击区域和状态映射。

优先本地加载；只有用户选择下载或更新时联网。限制压缩包大小、解压后大小、图片尺寸和帧数，拒绝路径穿越、脚本和外部追踪资源。素材出错回落静态图，不能影响路由服务。

已经拉取的参考库涵盖 DeepSeek、GPT、Claude、Gemini、Grok、Kimi、Qwen、智谱。鲸鱼挂件的原版图片／鸭叫并未授予通用再许可，暂只作为参考；新应用默认使用许可明确的非商用素材包，音效需另获授权或换成许可明确的替代音效。不可把“个人自用”当成所有素材天然获得授权。

## 9 安全隔离与迁移

开发根目录为 `<fork-workspace>`。当前原版安装目录和 `%USERPROFILE%\.codex-switcher` 只读，不作为开发输出目录。

启动新二进制之前必须完成：独立产品名／安装路径、Tauri identifier、进程名、深链、单实例锁、日志、更新源、端口、账号库、技能目录、Codex 测试配置和自启动项。推荐开发端口28180和28181，但必须检测占用，冲突时只报错，不能关闭原版进程。

第一阶段空账号库和合成测试数据；默认无自动代理接管、无后台登录刷新、无技能同步、无自启动。原项目的调试 HOME 开关不足以保证隔离，因为其他模块还有直接读取用户目录的路径。

迁移先预览账户类型、数量、数据版本和冲突，密钥不在预览里。保留来源 ID 映射、去重和事务校验；备份保存在仓库外的受限目录。Windows 使用 DPAPI／系统凭据存储，并设置只允许当前用户的访问权限。

OAuth refresh token 必须只有一个刷新拥有者：不能复制后让两个 Switcher 同时刷新。需要使用原版受支持的令牌租用接口，或在用户确认切换窗口后转移拥有权／单独重新登录。测试阶段不迁入正在使用的 refresh token。

账号迁移不自动迁移所有聊天历史。按需导入历史，并说明跨供应商发给谁、保留多久；诊断导出默认去掉令牌、Cookie、邮箱、正文、组织和账号标识。
