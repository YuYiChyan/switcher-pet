# Switcher Pet · macOS 自用开源版

## 安装和启动

解压 `SwitcherPet-macOS-universal.app.zip`，将 `Switcher Pet.app` 放入自己的
Applications 文件夹。通用二进制包含 Apple Silicon 和 Intel 两种架构。
这是自用预览包，采用 ad-hoc 本地签名，**没有 Apple Developer ID 签名及公证**。
首次运行可能受到系统安全提示限制；请通过 macOS 针对这个应用的“仍要打开”流程处理，
不要关闭全系统的安全检查。

默认静默启动桌宠及菜单栏；设置从桌宠右键菜单打开。
数据保存在 `~/.switcher-pet/`，不会附带或自动覆盖其他安装的账号数据。
代理默认端口为 18080；原程序已占用时，请先在设置里调整端口或自行退出原程序。

## 菜单栏用量

参照用户提供的 QuotaPeek 交互，在应用内部集成菜单栏显示：

- 切换总池、当前模型池或当前账号；可选择优先显示周额度。
- 默认优先显示受限账号的五小时额度；没有五小时限制时显示周额度。
- 百分比按配置倍率累加，可以超过 100%；`≈` 表示估算倍率。
- API 显示实际余额，币种分开；不会将不同币种相加。
- `—` 是未知，不是零；`*` 表示包含未知或上次记录。
- 菜单栏“立即刷新额度”或捏桌宠会主动刷新；并发动作合并为一次任务。
  刷新失败保留旧数据，不把网络故障误判为账号过期。

提供的独立 QuotaPeek 可执行文件与 QuotaPeek2 压缩包中的文件相同，
仅含 arm64 且内置固定旧用户目录。本版没有修改或再分发该不含源码的二进制，
而是复用 Switcher Pet 的额度缓存实现对应功能，避免另一进程争用账号凭据。

## 验证边界

发布构建检查通用架构、ad-hoc 签名、隔离启动和单元测试。
这些检查不代表已经在你的 Mac 上验证登录、真实账户网络、声音或桌宠交互。
原始账号密钥、个人配置和本地记录均不随包发布。
